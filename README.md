# KODEX: atualizações

Aqui ficam as versões do KODEX. As apps instaladas procuram sozinhas a versão mais recente em **Releases** e atualizam-se (o Android pede para confirmar "Instalar").

- `KODEX-<versão>-tv.apk`: telemóveis, TVs e boxes com Android 7 ou mais
- `KODEX-<versão>-antigas.apk`: boxes com Android 5 ou 6
- `KODEX-<versão>-emulador.apk`: emulador do PC
